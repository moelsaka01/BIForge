# How docs/INVENTORY.md was built

Written in our own words on 2026-10-16. Raw output is in `research/_raw/` (gitignored).

- **Hand-written lists** (`tools/inventory/manual-*.txt`): start screen, title bar, backstage, every ribbon tab and group, panes, canvas, Table / Model / DAX query / TMDL views, modeling features, Power Query ribbon, Options pages, dialogs, shortcuts, export. Basis: `research/ui-ribbon-commands.md` (ribbon command ids), the reference screenshots (local), Microsoft's public documentation as remembered, and the product's script bundles for the dialog list. Items taken only from public documentation or memory, not from the product, are: the Options page and setting names, the global shortcut keys (Ctrl+N/O/S/P/Z/Y/C/X/V/A, F11, Ctrl+G, Ctrl+D). They should be checked against Desktop before their implementation is called done.
- **Dialog inventory**: the file names of dialog chunks in `WebView2Resources/minerva/scripts` (about 55 names such as conditional formatting, data bars, export data, hotkey, theme, table view, sparklines, groups, report validator, quick save). Cloud dialogs (publish, sensitivity, OneLake, Fabric trial, invite) were left out.
- **Keyboard shortcuts**: the hotkey dialog bundle lists 28 accessibility shortcuts (focus between sections Ctrl+F6, show visuals as tables Ctrl+Shift+F11, show/hide tooltip Ctrl+Shift+F10, visual menu Alt+Shift+F10, multi-select Ctrl+Space, data point details Ctrl+H, clear selection Ctrl+Shift+C, annotations Ctrl+Alt+I, collapse/expand all tables Alt+Shift+1 and Alt+Shift+9, enter visual Ctrl+Right, exit Esc). The full global shortcut table is not in a script bundle (it is in the .NET host) and is still open.
- **Formatting cards per visual**: the report theme schema bundle (`desktop.reportThemeSchema.json.min.js`) defines, for 52 visual types, every card (formatting object) and its property names. `tools/re/theme-schema.mjs` prints them; `tools/inventory/visual-cards.json` keeps names and property counts only. Largest: line chart 278 properties in the `*` default style, bar and column charts 188.
- **DAX functions**: `crates/dax/examples/list_functions.rs` prints the catalog (317) and which are implemented.
- **M library**: `tools/re/m-names.mjs` lists `Family.Name` strings of `Microsoft.MashupEngine.dll` (781 matches, filtered to the standard library families, 652 names in `tools/inventory/m-names.txt`). Some may be internal; none were checked individually.
- **Open gaps**: the report ribbon's exact tab -> group -> control tree inside `desktop.min.js`, the Options dialog pages (hosted by .NET), the global shortcut table. They are tracked as inventory items, not claims.
