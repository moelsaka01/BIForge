# DAX black-box conformance harness – design (not built)

Goal: obtain trustworthy expected results for DAX semantics without analysing the native engine, and store them as test cases in `tests/dax/`.

## Approach
1. **Fixture models.** Small, purpose-built datasets (CSV generated by us, deterministic) loaded by hand into a local Power BI Desktop report that holds the model (tables, relationships, a few measures). No Microsoft sample content.
2. **Connect to the local engine.** While the report is open, Desktop runs a local Analysis Services instance on a dynamic localhost port. Find the port from the instance's workspace folder (a port file under the user's AnalysisServicesWorkspaces temp area) and connect over XMLA/ADOMD from a small client. Only read-only DAX `EVALUATE` queries are sent; the model is never modified.
3. **Case format.** Each case is a text file: fixture id, DAX query, expected columns and rows (types, values, BLANK, ordering rules), notes. Stored under `tests/dax/cases/<area>/` with fixture CSVs under `tests/dax/fixtures/`.
4. **Recorder script.** A script in `tools/dax-record/` (our own code) runs a list of queries against the live instance and writes case files. A human reviews results before commit.
5. **Replay.** A Rust test runner loads the fixture into DuckDB, evaluates each query with the BIForge DAX engine, and compares with the recorded expectation. Unsupported cases are reported as skipped, never as passed.

## Coverage plan
Filter context (CALCULATE, ALL/ALLEXCEPT/REMOVEFILTERS, KEEPFILTERS), context transition, relationships (one-to-many, bidirectional, inactive with USERELATIONSHIP), blank semantics, time intelligence, iterators, SUMMARIZECOLUMNS/ADDCOLUMNS/GROUPBY, sort and rounding rules.

## Risks and questions
- Recorded values are Microsoft engine output on our own data, behavioral facts rather than Microsoft assets. Approved by the project owner.
- The local instance exists only while the report is open, so recording is a manual, occasional step.
- Fixture reports (.pbix) are created by hand and stay local (gitignored).
- Port discovery and authentication need to be confirmed on this machine before building.
